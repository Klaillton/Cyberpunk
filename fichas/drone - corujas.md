## O que é

Três aves mecânicas **miméticas**. Não são Vespas. Não são o Condor. Não são veículo.

| Campo | Canon |
| ----- | ----- |
| Quantidade | **3** unidades |
| Papel | recon **noturno** e voo **silencioso** (sessão 012) |
| Combate | **sem arma** |
| Tamanho | menores que o Condor; no poleiro ao lado dele, parecem ainda menores |
| Payload | **nenhum módulo de mochila**. Não carregam Agent. Não carregam gente. |

- **Unmanned.** Ninguém monta.
- Pouso = **poleiro / barra**. Operador fica no chão, visor ou Neuralink.
- Pack (crianças e adultos) já viu voo básico na demo. Operação de verdade = quem Ryan ensinou (ir e vir, visor). Não assumir que o Pack inteiro voa as três sozinho numa op.

## Envelope

**Não** herdar os números do Condor (3 km / 8 km / 80 km / 190 km / 13 h). Isso é o pássaro grande.

As Corujas fazem o trabalho **perto e baixo**: corredor, rio, camp, trilha, perímetro do Pack. Noite é o perfil. De dia voam (demo 20/07), mas o desenho é silêncio + olho no escuro, não horizonte de 190 km.

| Campo | Estado no SoT |
| ----- | ------------- |
| Teto / rádio / placa / autonomia em km | **não anunciado** — não inventar |
| Perfil | baixo, silencioso, recon local |
| Sensores | visão noturna suficiente para recon; não é “lente de condor” |
| Controlo | visor externo e/ou Neuralink, um operador por ave ou revezamento |

Se a mesa precisar de número numa op: Ryan declara o alcance **na hora** e isso entra no próximo Finalizar. Até lá = perto o bastante para ver o rio seco / o corredor, longe o bastante para não ser o Condor.

## Uso em operação

- Podem ir **com** o corte do Reyes (leste / rio seco) sem substituir o Condor.
- Condor = teto e alerta longo. Corujas = olho baixo no chão que o céu não desceu.
- Silêncio no ar. Sem arma. Sem anunciar pacote. Sem SOP de mochila.
- Fora do Pack: não assumir que as três estão no bolso do Ryan (F16).
