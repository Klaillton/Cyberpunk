## O que é

Três aves **reais reconstruídas**. Não são drones pintados de coruja. Não são Vespas. Não são o Condor. Não são veículo.

| Campo | Canon |
| ----- | ----- |
| Quantidade | **3** unidades |
| Papel | infiltração + recon **próximo** + vigilância / OSINT, sobretudo **noite** |
| Combate | **sem arma** |
| Tamanho | menores que o Condor; no poleiro ao lado dele, parecem ainda menores |
| Payload | **nenhum módulo de mochila**. Não carregam Agent. Não carregam gente. |

- **Unmanned.** Ninguém monta.
- Pouso = **poleiro / barra**. Operador fica no chão, visor ou Neuralink.
- Pack (crianças e adultos) já viu voo básico na demo. Operação de verdade = quem Ryan ensinou (ir e vir, visor). Não assumir que o Pack inteiro voa as três sozinho numa op.

### Construção (mimetismo)

Ryan **captura a ave** (caçada **E013** — material biológico), preserva pele e plumagem, usa o corpo externo como matriz e **substitui o interior** por atuadores, sensores e rádio.

Quem olha para uma Coruja **vê uma coruja**. Não vê um drone parecido com coruja.

Espécie exata, se as três são da mesma espécie, e anatomia interna fina = **não anunciado**. Não inventar.

### Furtividade (não é invisibilidade)

A vantagem é **mimetismo + comportamento + percepção humana**, não camuflagem eletrônica.

| Camada | Quando | O quê |
| ------ | ------ | ----- |
| Voo | no ar | furtividade **acústica** — voo silencioso (já na âncora Stealth) |
| Pousada | no poleiro | furtividade **visual** — plumagem real, silhueta de ave |
| Imóvel | parada | furtividade **comportamental** — parece uma ave que simplesmente está ali |

**Falha de mimetismo:** alguém pensa “isso não é uma coruja”.  
**Não é falha:** alguém vê uma coruja no telhado. Pode comentar, fotografar, achar que “mora aqui”.

**Normalização:** voltar ao mesmo sítio vários dias vira “a coruja do lugar”. Presença prolongada é vantagem, não necessariamente risco. O Pack **não** ganha uma segunda missão de esconder a ferramenta.

### Ações base

Narra como **ave real**, não como câmera com penas. 1–2 beats de animal por cena bastam. O **payload** da ação é o sensor, não o show.

| Ação | O quê |
| ---- | ----- |
| Voar | silêncio até o ponto |
| Pousar / ficar | poleiro; some no ambiente |
| Olhar + ouvir | **sensores** (NV / térmico / áudio perto) — é o trabalho |
| Virar a cabeça / reagir | acompanha som ou aproximação, como coruja |
| Mudar de posto / voltar depois | sustenta “a coruja do lugar” |

Não reproduzir etologia completa. Sem arma, sem módulo, sem “ficar pairando como drone”.

**Frase de uso:** *a Coruja entra antes de nós e me diz o que tem lá dentro.*

Não herda funções de Vespa. Vespa = vigilância móvel / acompanhamento. Warden = suporte ao operador. Condor = recon aéreo **estratégico** (longe / movimento). Coruja = perto / informação.

## Envelope

**Não** herdar os números do Condor (3 km / 8 km / 80 km / 190 km / 13 h). Isso é o pássaro grande.

As Corujas fazem o trabalho **perto e baixo**: corredor, rio, camp, trilha, perímetro do Pack. Noite é o perfil. De dia voam (demo 20/07), mas o desenho é silêncio + olho no escuro, não horizonte de 190 km.

| Campo | Estado no SoT |
| ----- | ------------- |
| Teto / rádio / placa / autonomia em km | **não anunciado** — não inventar |
| Perfil | baixo, silencioso, recon local |
| Sensores | NV + térmico em **contraste** + IFF (ver abaixo) |
| Controlo | visor externo e/ou Neuralink, um operador por ave ou revezamento |

Se a mesa precisar de número numa op: Ryan declara o alcance **na hora** e isso entra no próximo Finalizar. Até lá = perto o bastante para ver o rio seco / o corredor, longe o bastante para não ser o Condor.

## Sensores

O visor (e o Neuralink, se o operador tiver) funde **visão noturna** com **térmico** no mesmo quadro — o mesmo tipo de contraste que um visor militar atual: o calor desenha em cima do escuro, não no lugar dele.

- **Noturno:** forma, terreno, trilha, silhueta.
- **Térmico:** corpo quente, motor, fogueira, alguém parado atrás de folhagem ou lona.
- **Contraste:** os dois juntos. Calor sem forma = suspeito. Forma sem calor = sucata / corpo frio / isca.
- **IFF:** marca o que o Pack já cadastrou (gente, veículo, as próprias aves, o Condor) como amigo no visor. O resto aparece como desconhecido até alguém confirmar. Não adivinha intenção. Não lê chrome. Não “identifica facção”.
- **Audição:** a escolha da coruja não é só visual. O visor passa áudio do ambiente (direcional, **perto**). **Não** é microfone de km. Alcance em número = não anunciado.

Não é lente de Condor. Não lê placa a 7 km. Alcance visual e de rádio **não** estão no SoT — só o tipo de olho/ouvido.

## Uso em operação

- Podem ir **com** o corte do Reyes (leste / rio seco) sem substituir o Condor.
- Condor = teto e alerta longo. Corujas = olho baixo no chão que o céu não desceu.
- Silêncio no ar. Sem arma. Sem anunciar pacote. Sem SOP de mochila.
- Fora do Pack: não assumir que as três estão no bolso do Ryan (F16).

## Trava de cena

- Não narrar como drone pintado / casco com adesivo de penas. É **ave real reconstruída**.
- Não narrar como drone de combate / Vespa. Não “Coruja = Vespa melhor”.
- Não emprestar envelope do Condor. Não inventar espécie, km de rádio, autonomia, nem etologia além das **ações base**.
- Ver uma coruja **não** quebra a furtividade. Quebra quando alguém identifica a máquina.
- Não montar gente.
- Não fundir as três numa só “coruja genérica” se a conta de unidades importar — são **três**.
- IFF **não** é omnisciência. Sem cadastro = desconhecido.
- **Não** aumentar capacidade (arma, módulo, envelope) “porque o mimetismo é bom”. O ganho é custo operacional baixo — a ferramenta não precisa ser escondida.
