## 3. Respostas às perguntas do plano

### 3.1 Quais exigiriam rolagem sob a nova camada?

**Quase todos os combates e stealth ops com oposição ou falha interessante:** J001 (partes), I001, I002, T008. Scavs limpas e queima de corpos: em geral **não**.

### 3.2 Quais são legítimos por vantagem/preparação?

**Todos os listados** têm prep (drones, intel, silenciadores, Mule, Kaz, escuridão). A camada **preserva** isso como mods e DV realistas — não nerfa Ryan; exige **mostrar** o teste quando há risco.

### 3.3 Skills/roles ainda só narrativa?

| Área | Estado pós Fases 1–4 |
| ---- | -------------------- |
| Combate / stealth / drones Ryan | Coberto (loadout + 02/04/08/house) |
| Maker / craft | 08 |
| Veículos / Mule | 09 |
| NET (Alex) | 10 (MVP) |
| Solo Combat Awareness (Jax/Reina) | 07 resumo — **ainda leve** (sem track de pontos por cena na ficha) |
| Operator / Credibility | 07 resumo — ok para mesa |
| Medicine ranks detalhados | 03+07 — ok MVP |
| Stealth skill na ficha Ryan | **Fechado:** Stealth **4** (Roll20). Ops furtivas 001–016 = prep + drones, sem retcon. |
