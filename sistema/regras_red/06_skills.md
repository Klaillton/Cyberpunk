# Skills — atalho de mesa

**Pré-requisito:** [01_core.md](01_core.md).  
**Valores:** sempre da **ficha** do personagem. Este arquivo só diz **qual STAT** e quando usar.

```text
Total = STAT + Skill + 1d10 + mods
```

Sem skill na ficha: **STAT + 1d10** (untrained) — declarar.

---

## 1. Skills por STAT (campanha)

| STAT | Skills frequentes |
| ---- | ----------------- |
| **INT** | Perception, Conceal/Reveal, Tracking, Education, Business, Criminology, … |
| **REF** | Handgun, Shoulder Arms, Archery, Drive Land Vehicle, Piloting, … |
| **DEX** | Evasion, Athletics, Stealth, Contortionist, Dance, … |
| **TECH** | Basic Tech, Cybertech, Electronics/Security Tech, Weaponstech, First Aid, Paramedic, Surgery, … |
| **COOL** | Bribery, Interrogation, Persuasion, Streetwise, Trading, Acting, … |
| **WILL** | Concentration, Resist Torture/Drugs, Endurance, … |
| **EMP** | Human Perception, Conversation, Persuasion (social fino), … |

Combate: ver [04_armas](04_armas.md). Craft: [08_techie](08_techie.md). Veículo: [09](09_veiculos.md).
