## 1. Role Ability: Maker (resumo)

A ficha define **ranks** por sub-habilidade (nomes do core / ficha):

| Área (ficha Ryan) | Rank atual (exemplo) | Uso em mesa |
| ----------------- | -------------------- | ----------- |
| Upgrade Expertise | 3 | Upgrades / reduzir custo HL em implantes elegíveis (core) |
| Invention | 1 | Itens **novos** (protótipo, drone novo, gimmick) |

Outras capacidades Techie via **skills**: Basic Tech, Electronics/Security Tech, Weaponstech, etc. (ficha).

**Regra de campanha:** rank alto = DV mais favorável e tempo menor — **não** sucesso automático em invention sob risco.

## 2. Tipos de trabalho

| Trabalho | O quê | Resolução típica |
| -------- | ----- | ---------------- |
| **Field repair / Jury rig** | Consertar sob pressão | Basic Tech / skill + 1d10; duração limitada se jury rig |
| **Fabrication** | Produzir peça/item conhecido | Tempo (horas–dias) + materiais; teste se falha importa |
| **Upgrade** | Melhorar gear existente | Upgrade Expertise + materiais; anotar no loadout |
| **Invention** | Algo **novo** | Invention rank; DV alto; protótipo; risco de falha/atraso |
| **Install chrome** | Implante | Medtech/Surgery + Tech; HL (detalhe Fase 3); Stitch/Doc se cena |

---

## 3. Tempo e materiais (faixas MVP)

| Escala | Exemplos | Notas |
| ------ | -------- | ----- |
| Minutos–1h | Jury rig, swap módulo, reparo leve | Em combate: ação + teste |
| Horas (1 sessão) | Peça, upgrade menor, calibração drone | Oficina Pack ajuda (ficção) |
| Multi-dia | Protótipo serio, linha de produção, Condor-class | Downtime + [downtime_ryan](../../logs/downtime_ryan.md) |
| Multi-sessão | Sistema grande (Node, casas) | Já narrado; não re-rolar o passado |

**Materiais:** se consumir P-item / chrome / chapas → **economia** no Finalizar.  
Sem material = DV pior, scrap, ou impossível.

**Oficina Pack / Tio Gringo:** vantagem de ficção (ferramentas, ajudantes) — declarar **+1 ou DV −1**, não +5 mágico ([house](../house_rules/regras_campanha.md)).

## 4. Drones

| Ação | Regra |
| ---- | ----- |
| Controlar / programar sob pressão | Tech skill + 1d10 (ou Electronic Security) |
| Recon / jam / distração | Setup = teste; efeito = mods para stealth/combate ([house](../house_rules/regras_campanha.md)) |
| Combate com drone armado | [02](02_combate.md) + stats do loadout |
| **Warden** | Terrestre F03; proteção/utilidade; não voa |
| **Vespas** | Loadout de bolso / marcha |
| **Condor / Corujas** | Pack (F16); não assumir em toda cena NC |
| **Enxame** (E017) | Só ideia até protótipo no SoT |

Criar drone novo = **Invention / Fabrication** + materials + entrada no loadout após sucesso.

---

## 5. O que não inventar

- Stats de arma 10d6 “porque é Techie” sem tempo/custo/teste.  
- Drones milagrosos sem rank/materiais.  
- Alterar loadout canônico sem Finalizar / cena.  
- Confundir Maker com netrunning (Alex / Interface — Fase 4).

---

## 6. Pipeline rápido

```text
O que quer fazer? → repair / fabricate / upgrade / invent
Materiais e tempo OK?
Teste (skill + Maker se aplicável) se risco/falha importa
Sucesso → anotar loadout / economia / downtime
Narrar
```
