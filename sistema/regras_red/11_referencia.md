## Quando rolar

| Situação | Ação |
| -------- | ---- |
| Trivial / sem risco | Não rolar |
| Risco / oposição / custo grave | Rolar |

```text
Total = STAT + Skill + 1d10 [+ mods]  vs  DV  ou  oposto
```

Apresentar: d10 · STAT · Skill · mods · total · DV/oposto · resultado · consequência.
