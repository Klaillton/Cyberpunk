# House rules da campanha

**Hierarquia:** [00_integridade](../regras_red/00_integridade_regras.md).

## 2. Stealth

```text
Não ser percebido  ≠  Ser invisível  ≠  Matar sem teste
```

### Quando testar

Sempre que houver **risco real** de ser visto/ouvido/detectado e a falha mudar a cena (alarme, reforço, perda de surpresa).

### Resolução

1. Ativo: Stealth / Hide / Silence (ou skill equivalente da ficha) + STAT + 1d10.  
2. Passivo: Perception / Awareness do vigia + STAT + 1d10 (**oposto**).  
3. Fatores de ficção → **mods** (não inventar números grandes):

| Fator | Direção típica |
| ----- | -------------- |
| Escuro / cobertura / silenciador | + ao stealth / − à percepção |
| Luz, terreno aberto, barulho | − ao stealth |
| Sensores, câmeras, Kiroshi, drones inimigos | + à percepção ou DV extra |
| Drones aliados (recon, jam) | + ao stealth **se** a ficha/gear justificar e houver ação de setup |
| Alvo em alerta máximo pós-tiro | − ao stealth / + percepção |

4. Falha: detecção parcial ou total — **não** rebobinar; narrar consequência.  
5. Sucesso: permite **ataque com surpresa** ([02_combate](../regras_red/02_combate.md)), ainda com rolagem de ataque/dano.

## 3. Drones (fatos duros + mesa)

| Ativo | Regra de mesa |
| ----- | ------------- |
| **Warden** | Terrestre / mochila (F03). **Não voa.** Utilidade, cobertura, projeção, apoio — não “drone aéreo genérico”. |
| **Vespas** (Hornet, Vesper, Barbed) | Recon, EW, distração, combate leve conforme ficha (F12). |
| **Condor / Corujas** | Miméticos operacionais no **Pack** (F16). Alerta de longo alcance; **não** assumir que estão no loadout de bolso de Ryan em toda cena fora do Pack. |
| **Enxame mini-drones** | Só ideia (E017) — sem stats até existir protótipo no SoT. |

Controlar / posicionar drone sob pressão = teste Techie / skill relevante ([01_core](../regras_red/01_core.md)).  
Drones **não** concedem sucesso automático em stealth ou combate.

## 4. Anti-super-herói (campanha)

Ryan (e a crew) podem ser **excepcionais** por ficha + prep + gear.

**Proibido:**

- “Ele é o melhor, então acerta sem rolar” sob oposição/risco.  
- +mods sem origem (ficção + regra).  
- Tratar F15 / drama como bônus numérico de combate.

**Permitido:**

- DV realistas para mooks em má posição.  
- Surpresa após stealth bem-sucedido.  
- Prep (recon, jam, silenciador) como **mods listados**.
